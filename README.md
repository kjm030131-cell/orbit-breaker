**사용자(총괄 김재민) 작업 방식**
- 항상 **한국어**로 답한다.
- **계획을 먼저 짧게 말하고, 허락을 받은 뒤** 끝까지 진행한다. 끝나면 바뀐 점을 짧게 보고한다.

- "확인만 해봐", "말하고 허락받고 수정" 이라고 하면 **절대 바로 고치지 않는다.** 원인·제안만 보고한다.
- AI 에셋 프롬프트는 **에셋 하나당 완성형 1개**. 이미지·음악 AI용은 영어, 음성(ElevenLabs v3)은 한국어 대사 + 영어 감정 태그(`[urgent]` 등).

- 너무 짧게 지나가는 연출, 글이 잔뜩 쓰인 설명, "AI가 만든 티"(테두리 없는 박스, 어색한 장치)를 싫어한다. UI는 기존 9-slice 테두리 에셋을 쓴다.

**배포 규칙 (사고 방지)**
- 배포는 **GitHub `main`에 push 하는 것 하나뿐.** GitHub Actions가 빌드 → 문법 검사 → 테스트 → 대전 서버 → Pages 순서로 자동 배포한다.

- 같은 저장소를 여러 채팅방이 동시에 고친다 → 작업 직전 `git pull`, push 전 `git pull --rebase`, 남의 영역은 최소 수정.

## 3. 게임 설명

### 3-1. 개발 배경
- 학술제 부스에서 **누구나 링크 하나로 바로** 하고, **학번으로 기록을 경쟁**하는 게임. 상위권 시상 예정.
- 짧은 판(120초)에서도 실력 차가 드러나도록 연쇄 폭발·배율·회피 보상·보스 기록을 설계.
- 지향점: 매끈한 SF보다 **리얼로봇** 감성(무게감 있는 기체, 잔해가 떠도는 전장), 트리플A 게임 같은 연출.

### 3-2. 한 판의 흐름
1. 타이틀 → **파일럿 등록**(이름·학과·학번) → **작전 규칙 확인 창**('확인했습니다'를 눌러야 진행)
2. **기체·옵션 장비 선택** (고르는 즉시 옆 3D 기체에 장비가 붙어 보임)
3. 출격 브리핑 → **캐터펄트 출격 컷씬**(오퍼레이터·파일럿 음성)
4. **120초 전투 4단계**: 1단계 선발 정찰대(0초) → 2단계 돌격 드론(20초) → 3단계 정예 호위기(45초) → 최종 단계 지휘기(60초~)
5. 보스 등장 연출(약 6.8초, 이때 **타이머 정지**) → 보스 3웨이브
6. 결과 화면: 점수·등급(S/A/B/C)·전체 순위, 보스 격파 시 **격파 인증 카드(N번째 격파자)**

### 3-7. 보스 — 지휘기 케르고그모스 (3웨이브)
1. 붉은 **약점 포드 3개**를 쏘거나 베어서 부순다 (포드 1개 +1,200)
2. 다 부서지면 보스가 **5초간 정지** → 가까이 붙어 **사벨(또는 메가 빔)로 베기**
3. 1·2번째 베기 = 1차·2차 격파(+3,000, 분노: 공격 강화·자폭 드론 호위), **3번째 베기 = 처치(+12,000)**
- 5초 안에 못 베면 그 웨이브의 약점이 다시 생긴다.
- 마지막 웨이브에서 보스가 물러난다(플레이어보다 느림). **작전 구역 안에서만** 움직이고 경계에서는 옆으로 미끄러진다.
- 화면 안내: 등장 연출(공략 2단계 자막), 약점 표식·화면 밖 화살표, 정지 중 "지금! 가까이 붙어 베기" + 남은 시간 막대, 목표창 "보스 n / 3".

### 3-8. 점수 시스템 (점수 v2, 10/30 12:30 개편 — 단순화)
- **격추 1기 = 300점** (라이플·사벨·스킬 상관없음, 맞힐 때마다 주던 점수는 없앰). 정예기 +1,500 · MS +1,200 · 검투기 +1,800 추가.
- **콤보가 유일한 배율**: 3.5초 안에 다음 적을 잡으면 이어짐, 5킬 ×1.5 / 10킬 ×2 / 15킬 ×2.5 / 20킬 ×3(최대). **맞으면 콤보가 끊김.** 조준선 옆에 "콤보 n · ×배율" + 남은 시간 막대.
- **연쇄 폭발**: 베어 날린 적이 다른 적·잔해에 부딪히면 **1기당 +500** (단계 없음). 자폭 드론 유폭도 1기당 +500.
- **보스**: 약점 피해 1당 120, 약점 1개 +1,200, 1·2차 격파 각 +8,000, 처치 +40,000(콤보 배율 미적용).
- 기타: 저스트 회피 300, 보급 컨테이너 600, 검투기 상대 패리·카운터 보너스.
- **생존 보너스**: 안 죽고 끝내면 +3,000 (고정).
- 없앤 것: 15초 무피격 배율, 최종 단계 ×2, 단계별 연쇄 점수(6연쇄 7,200 등).
- 등급: S 130,000 / A 85,000 / B 45,000 (v2 기준 임시값, `src/12-ui.js` GRADE).

## 5. 기술 구현

### 5-1. 구조
```
플레이어 브라우저 (three.js 렌더링·전투 로직·Web Audio·서비스 워커)
   ├─ HTTP ─→ Cloudflare Pages (게임 파일, Pages Functions = 순위·관리자 API) ─→ D1(SQLite)
   └─ WebSocket ─→ 대전 서버 (Durable Object, 방마다 1개, 명중·체력·스킬 서버 판정)
GitHub Actions: push → 빌드·문법검사·테스트(65개) → 대전 서버 + Pages 자동 배포
```

## 6. 보안 · 공정성
- **서버가 규칙을 강제**: 출격 횟수(학번당 3회)·최고점·보스 격파 기록은 서버가 관리. 클라이언트는 결과만 보고.
- **의심 기록**: 출격 3초 미만, 또는 6초 미만인데 점수가 있는 판 → 점수를 음수로 저장, 순위 제외, 관리자 화면에 "의심" 표시.
- **1:1 대전 서버 권한 판정**: 입력만 보내고 명중·피해·체력·스킬은 서버가 계산(조작으로 이길 수 없음). 지연 보정(보간, 근접 되감기 최대 160ms, 입력 버퍼).
- **관리자**: 비밀번호는 저장소에 없음(GitHub Secret → 배포 때 Pages 비밀값). 틀리면 0.9초 지연. 모든 삭제는 자동 백업 후 복원 가능.
- **요청 폭주 대비**: 순위·명예의 전당 30초 서버 캐시(요청이 몰려도 DB 읽기 증가 없음), 출격 시작·결과 보고 IP당 분당 40회 제한.
- **개인정보**: 순위표 학번은 가운데를 가림(예: 2026****34). 학번 전체는 관리자만.
- **저장소 비공개**, Cloudflare API 토큰은 GitHub Secret.
- **운영 이슈 기록**: 10/30 01시 D1 무료 일일 읽기 한도(500만 줄) 초과로 순위 서버 중단 → 캐시·조회 간격 개선 + 유료 요금제 전환(월 5달러, 포함량 넉넉). 예산 알림(1달러) 권장.

## 7. 차별성 · 강점
- **설치 없는 웹에서 콘솔급 3D 메카 액션 + 서버 판정 1:1 대전**을 함께 제공.

- **대회 운영 도구 내장**: 실시간 순위, 보스 격파 배지·명예의 전당, 관리자 페이지(삭제·복원·마감·CSV).
